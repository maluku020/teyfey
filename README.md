# Teyfey

Eigen IPTV-app (TiviMate-stijl) voor Android-telefoon en Chromecast met Google TV.

**Nieuwste APK (altijd):** https://github.com/maluku020/teyfey/releases/latest/download/Teyfey.apk  ·  kort: tinyurl.com/teyfey

Elke push naar `main` bouwt automatisch een nieuwe APK (GitHub Actions) en zet die als nieuwe release online.
Ondertekend met `teyfey.keystore` (dezelfde sleutel als alle eerdere versies, zodat updates over de oude app heen installeren).

De app bevat geen zenders of inloggegevens; je logt in met je eigen abonnement.
